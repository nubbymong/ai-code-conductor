## 2026-10-11 -- Repository renamed to nubbymong/ai-code-conductor: slug edits for 2.1.1-beta.3

**What.** GitHub renamed the repository from `nubbymong/claude-command-center`
to `nubbymong/ai-code-conductor`; the old name redirects. This change points
the scripts and docs at the new slug: `scripts/file-advisory.mjs` (the REPO
constant and the advisory's package name), `scripts/gen-changelog.js` (every
CHANGELOG.md tag link), `scripts/release.js`, `scripts/promote.js`,
`README.md`, `CONTRIBUTING.md`, `PRIVACY.md`,
`.github/ISSUE_TEMPLATE/config.yml`, `docs/security-embargo-runbook.md` (the
GHSA fork name follows the repo name) and `.claude/skills/LoopReady/SKILL.md`.
CHANGELOG.md is regenerated, and What's New gets a 2.1.1-beta.3 line: the new
home, old links redirect, restart once if no update shows.

**Why it matters.** The advisory-filing script posts a file body. GitHub
answers a write to a renamed repository with a 307, which a file upload
cannot replay, so filing against the old slug would fail. The rest worked
only through redirects.

**Kept on purpose.** `DEFAULT_REPO` in `src/main/github-update.ts` stays the
old slug in beta.3 (the startup soft-switch adopts `RENAMED_REPO`; flipping
the default is a 2.2 change under ADR-009). `RENAMED_REPO` never changes. No
`src/main` change. Test fixtures, the `User-Agent` strings, the dev
launcher's process match in `scripts/ccc.cmd`, `tests/live/fleet.example.json`,
installer file names and other frozen identifiers keep the old name.
